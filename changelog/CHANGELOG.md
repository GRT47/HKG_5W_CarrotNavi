# HKG 5W CarrotNavi Bridge 변경 이력

일반 사용자분들이 보기 쉽게 버전별 주요 변화와 해결된 문제를 정리한 문서입니다.

---

# 1.3.6 (2026-11-22) · HMG-API 패키지 1.2.1 포함

## :sparkles: 새 기능
- **순정 전체 앱 목록 · 사용자 버튼(★)에 CarrotNavi 추가** (HMG-API 설치 차량)
  - 순정 전체 앱 메뉴에 `CarrotNavi` 아이콘이 추가되고, 순정 **설정 → 버튼 → 사용자 버튼(★)** 선택지에서도 `CarrotNavi`를 지정할 수 있습니다.
  - 앱 아이콘이나 ★ 버튼을 누르면 CarrotNavi 전체화면 대시보드가 바로 열립니다. (최초 적용 시 1회 재부팅 필요)
- **순정 우측 분할화면에 CarrotNavi 연결 상태 표시** (HMG-API 설치 차량)
  - 오른쪽 분할화면에 **콤마 기기 연결 · 차량 GPS 위성/신호 · 무선 연결(핫스팟/WiFi)** 상태를 실시간으로 보여줍니다.
  - 카드를 터치하면 CarrotNavi 전체화면 대시보드가 열립니다.
  - 순정 **설정 → 화면 → 분할 화면**에서 `CarrotNavi` 체크만 한 번 켜면 바로 표시됩니다.
- **WiFi(Client) 모드에서도 순정 LTE·음악 스트리밍 유지** (HMG-API 설치 차량)
  - WiFi(Client)로 연결했을 때 차량 LTE가 끊겨 순정 음악 스트리밍이 안 되던 문제를 해결해, 콤마(WiFi)와 순정 스트리밍·블루링크/기아 커넥트(LTE)를 동시에 사용할 수 있습니다.
  - HMG-API 앱 설정에서 켜고 끌 수 있으며, 최초 적용 시 1회 재부팅이 필요합니다.
- **HMG-API 애드온 기능 자동 설치·업데이트**
  - 기존 사용자도 자동 업데이트(OTA)만으로 함께 설치·갱신되며, 나중에 HMG-API를 설치한 차량도 다음 시동(내비 켜짐) 때 자동으로 추가됩니다.
  - HMG-API `1.1.0-rc.8` 버전에서 앱 메뉴 · 사용자 버튼(★) · 분할화면 위젯 및 WiFi(Client) LTE 유지 기능 정상 동작이 확인되었습니다.

## :lady_beetle: 수정된 문제
- (`carrotbridge-panel v1.2.1`) 부팅 직후 `WiFi(Client)`가 차량 LTE보다 먼저 연결될 때 기본 회선·DNS·IPv6 경로가 WiFi로 넘어가 순정 음악 스트리밍이 끊기던 문제
- USB 케이블(ADB)로 설치할 때 연결이 끊기던 문제

# 1.2.7 (2026-11-10)

  - 순정 와이드 화면에 맞춘 카드형 레이아웃으로 새로 만들고, 안드로이드 4.4에서도 깨지지 않는 깔끔한 아이콘을 적용했습니다.
