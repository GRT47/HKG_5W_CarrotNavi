# HKG 5W CarrotNavi Bridge 1.3.6

## :sparkles: 새 기능
- **순정 전체 앱 목록 · 사용자 버튼(★)에 CarrotNavi 추가** (HMG-API 설치 차량)
  - 순정 전체 앱 메뉴에 `CarrotNavi` 아이콘이 추가되고, 순정 **설정 → 버튼 → 사용자 버튼(★)** 선택지에서도 `CarrotNavi`를 지정할 수 있습니다.
  - 앱 아이콘이나 ★ 버튼을 누르면 CarrotNavi 전체화면 대시보드가 바로 열립니다. (최초 적용 시 1회 재부팅 필요)
- **순정 우측 분할화면에 CarrotNavi 연결 상태 표시** (HMG-API 설치 차량)
  - 순정 내비게이션 오른쪽 분할화면에 **콤마 기기 연결 상태 · 차량 GPS(위성/신호) · 무선 연결(핫스팟/WiFi)** 카드를 실시간으로 보여줍니다.
  - 분할화면 카드를 터치하면 CarrotNavi 전체화면 대시보드가 바로 열립니다.
  - 자동 설치 후 순정 **설정 → 화면 → 분할 화면**에서 `CarrotNavi` 체크를 한 번만 켜면 바로 사용할 수 있습니다.
- **WiFi(Client) 모드에서도 순정 LTE·음악 스트리밍 유지** (HMG-API 설치 차량)
  - 기존에는 WiFi(Client)로 콤마와 연결하면 차량 LTE가 끊겨 순정 음악 스트리밍 앱 등에서 통신 오류 안내가 나오던 문제를 해결했습니다.
  - 이제 콤마 통신은 WiFi로 연결하면서 순정 음악 스트리밍과 블루링크/기아 커넥트는 차량 LTE로 동시에 이용할 수 있습니다.
  - HMG-API 앱 설정의 **WiFi(Client) 연결 시 LTE 기본 회선 유지** 스위치로 언제든 켜고 끌 수 있으며, 최초 적용을 위해 **1회 재부팅**이 필요합니다.
- **분할화면·앱 메뉴 기능 자동 설치·업데이트**
  - 이미 사용 중인 차량도 별도 파일 설치 없이 자동 업데이트(OTA)만으로 해당 기능이 함께 설치·갱신됩니다.
  - HMG-API가 없는 차량은 기존 그대로 동작하며, 나중에 HMG-API를 설치하면 다음 시동(내비게이션 켜짐) 때 자동으로 추가됩니다.
- **동작 확인 환경**
  - HMG-API `1.1.0-rc.8` 버전에서 앱 메뉴 · 사용자 버튼(★) · 분할화면 위젯 및 WiFi(Client) LTE 유지 기능 정상 동작이 확인되었습니다.

## :zap: 개선된 점
- **헤드유닛 저장공간 수명 보호 및 쾌적한 동작** (`1.3.5` 포함)
  - 매초 기록되던 상태 파일과 실행 로그를 내부 저장소 대신 메모리(RAM)에 저장하도록 바꿔 불필요한 저장장치 쓰기를 없앴습니다.
  - 로그 용량이 무한정 커지지 않도록 자동 정리하며, 예전 임시 경로 파일도 실행 시 깔끔하게 정리합니다.
